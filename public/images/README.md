# Images Directory

This directory contains static images used in the application.

## Operating System Images

Place the operating system images here with the following filenames:

### Drive Manual Image
- `drive-manual.jpg` (or `.png`, `.webp`, `.jpeg`)

The image should show a roller blind manual drive mechanism with a beaded chain.

### Drive Motor Image
- `drive-motor.jpg` (or `.png`, `.webp`, `.jpeg`)

The image should show a tubular motor for automated roller blinds.

**Supported formats:** JPG, PNG, WebP, JPEG

## Quote / Proposal PDF logo (Arquiproductos)

To show a default logo in the Quote PDF when the dealer has no logo set, place your image at:

- `Arquiproductos.png`

The PDF will use it in the top-left header. If the file is missing, a placeholder box is shown.

## Product type cards (configurator)

Images for product type selection (Roller Shade, Dual Shade, Accessories, etc.):

- `Roller Shade.png`, `Dual Shade.png`, `Triple Shade.png`, `Drapery.png`, `Awning.png`, `Window Film.png`
- **Accessories:** add `Accessories.png` (or `Accesories.png`) so the Accessories card shows the image instead of the placeholder.
